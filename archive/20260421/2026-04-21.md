Goal: run an ensemble including input setup

# 0. activate your environment

Use your environment name (probably `pecan-all`)

```
conda activate...
export HOST_ARGS='sbatch -n4 --mem=12G --mail-type=ALL'
```

# 1. Clone workflow repo

```
cd /your/working/dir
git clone https://github.com/ccmmf/workflows/
cd workflows
git checkout phase-3
cd 3_rowcrop
```

# 2. Fetch climate and management data

Skipping the ~50GB mslsp directory for today. The other managements add up to a bit under 10 GB.

```
aws s3 sync --endpoint-url=https://s3.garage.ccmmf.ncsa.cloud --exclude='mslsp/*' s3://carb/management/ ./data_raw/management
aws s3 sync --endpoint-url=https://s3.garage.ccmmf.ncsa.cloud s3://carb/data_raw/ERA5_CA_nc ./data_raw/ERA5_CA_nc
aws s3 cp --endpoint-url=https://s3.garage.ccmmf.ncsa.cloud s3://carb/data_raw/ca_biomassfiaald_2016_median.tif data_raw/ca_biomassfiaald_2016_median.tif
aws s3 cp --endpoint-url=https://s3.garage.ccmmf.ncsa.cloud s3://carb/data_raw/ca_biomassfiaald_2016_stdv.tif data_raw/ca_biomassfiaald_2016_stdv.tif
aws s3 cp --endpoint-url=https://s3.garage.ccmmf.ncsa.cloud s3://carb/data/workflows/phase_3/magic_demo_data_20260421.tgz .
tar xzf magic_demo_data_20260421.tgz
```

(If you get tired of `--endpoint-url=https://s3.garage.ccmmf.ncsa.cloud`, you can add `endpoint_url = https://s3.garage.ccmmf.ncsa.cloud` to your `.aws/config`.
Note the dash-vs-underscore difference of `-url=` on the command line vs `_url = ` in the config file.)

Convert climate data to Sipnet format

Running this for the whole state at once -- If you want to subset more, make a version of ca_half_degree_grid.csv that contains only the cells of interest.

```
$HOST_ARGS ./01_ERA5_nc_to_clim.R \
	--site_era5_path=data_raw/ERA5_CA_nc \
	--site_sipnet_met_path=data/ERA5_CA_SIPNET \
	--site_info_file=data_raw/ERA5_CA_nc/ca_half_degree_grid.csv \
	--start_date=2016-01-01 \
	--end_date=2023-12-31 \
	--n_cores=4
```
(If you downloaded `magic_demo_data_20260421.tgz` before 2026-04-21 15:00 PDT, you may get an error about column "id" not being found. If so, edit data_raw/ERA5_CA_nc/ca_half_degree_grid.csv to change column name `grid_id` to `id`.)



# 3. Set up site info

Note that this needs the crop management info in place first


```
head -n4 ../data/design_points.csv > demo_design_points.csv
../tools/build_site_info.R --location_file=demo_design_points.csv
```



# 4. Fetch initial conditions

If you have pulled `data/IC_prep/` from magic_demo_data_20260421.tgz, this should run very quickly. If not, expect a few minutes (it queries SoilGrids and ECMWF soil moisture APIs for each site)

```
./02_ic_build.R \
	--site_info_path=site_info.csv \
	--pft_dir=data_raw/pfts \
	--data_dir=data/IC_prep \
	--ic_outdir=data/IC_files
```

(Tara had an issue here with her conda environment not finding the "tidyverse" package.
We worked around it with 'install.packages("tidyverse") inside an interactive R session.)


# 5 build event files

This should recreate what you already pulled in magic_demo_data_20260421.tgz

```
$(HOST_ARGS) ./02a_build_events.R \
  --site_info_path=site_info.csv \
  --mgmt_file_dir=data_raw/management \
  --event_outdir=data/events_
diff -q --recursive data/events/ data/events_
# If no differences: rm -r data/events_
```

# 6. build a multisite settings file and a run directory

```
./03_xml_build.R \
	--ic_dir=data/IC_files \
	--end_date=2023-12-31 \
	--site_file=site_info.csv \
	--output_file=settings.xml \
	--output_dir_name=output
./04_set_up_runs.R --settings=settings.xml
```


# 7. Execute model

```
export NCPUS=8
ln -s [your/path/to]/sipnet/sipnet sipnet
$HOST_ARGS ./05_run_model.R --settings=output/pecan.CONFIGS.xml
```
